# PantryPilot

PantryPilot es una app web mobile-first para inventariar freezer, pantry y heladera.

## Requisitos

- Node.js
- npm

## Instalar

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

La app usa `localStorage` para guardar los items del inventario.
